# Price List Automation Portal

A high-fidelity web application prototype for automating the monthly floor price list preparation and approval workflow.

## Features
- Multi-level approval workflow
- Role-based access control
- ERP integration tracking
- Finance intervention support

## Tech Stack
- React 18 with TypeScript
- Tailwind CSS
- React Router

## Getting Started
```bash
npm install
npm run dev
```

## User Roles
- Business User
- Approver (Sales Head, SBU Head, President, CEO)
- Finance Team
- Admin
